# Question editor

Open a session and use the editor to add, reorder and edit questions. Changes are saved when you press **Save**.

## What you can set

- **Question text**: what attendees read. For Treasure Hunts this is the clue message.
- **Options**: add as many as you need. Each shows as a choice on phones.
- **Correct option and points** (quizzes): mark the right answer and set points for it.
- **Time limit** (quizzes): 5 to 120 seconds. See [Quiz](/help/quiz).
- **Images**: add an image to a question, or use images as the content of a [comments session](/help/comments).
- **Clue label and choices** (treasure hunts): see [Treasure Hunt](/help/treasure-hunt).

<Callout>
Short, legible text works best on a projector. Treasure Hunt labels are limited to 60 characters.
</Callout>

Let the [AI assistant](/help/ai-assistant) draft a set of questions, then edit them here.
